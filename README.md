Não é apenas um site estático — é uma aplicação completa com gerenciamento de estado, autenticação, integração com IA e pipeline de CI/CD automatizado.

### 🎯 O Que Este Projeto Demonstra

- ✅ **Desenvolvimento Frontend Moderno**: React 19 + TypeScript com arquitetura componentizada
- ✅ **Gerenciamento de Estado**: Redux Toolkit para estado global escalável
- ✅ **DevOps & Automação**: GitHub Actions com deploy automatizado
- ✅ **Integração de APIs**: Google Gemini AI para chat inteligente
- ✅ **Boas Práticas**: Código limpo, tipagem forte, versionamento Git

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou yarn
- Conta no Google AI Studio (para o chat com IA)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/haiomiirio/jos--tadeu-nascimento---cloud---infra-portfolio.git

# Entre no diretório
cd jos--tadeu-nascimento---cloud---infra-portfolio

# Instale as dependências
npm install

# Configure as variáveis de ambiente
# Crie um arquivo .env.local e adicione:
# VITE_GEMINI_API_KEY=sua_chave_aqui

# Execute o projeto
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

### Comandos Disponíveis

```bash
npm run dev          # Inicia servidor de desenvolvimento
npm run build        # Gera build de produção
npm run preview      # Preview do build de produção
npm run deploy       # Build + deploy automatizado
```

## 📦 Deploy Automatizado

O projeto conta com pipeline CI/CD configurado via **GitHub Actions**:

1. **Push para `main`** → Dispara workflow automático
2. **Build com Vite** → Otimização e minificação
3. **Deploy no GitHub Pages** → Site atualizado automaticamente

Todo o processo acontece sem intervenção manual, demonstrando conhecimento em automação e DevOps.
