## 🚀 Execução local

### Pré-requisitos
- Node.js 18 ou superior
- npm ou yarn

### Passos

```bash
git clone https://github.com/haiomiirio/jos--tadeu-nascimento---cloud---infra-portfolio.git
cd jos--tadeu-nascimento---cloud---infra-portfolio
npm install
npm run dev
```

A aplicação estará disponível em:  
**http://localhost:5173**

## 🔄 Deploy

O projeto utiliza **GitHub Pages** para publicação automática.

Cada atualização no repositório gera um novo build, permitindo acompanhar a evolução do projeto de forma simples e prática.
